# LWOLF

Single-page portfolio demo.

## Direction
- retro cut-paper / punk editorial meme-coin site
- vertical page scroll with pinned horizontal GSAP chapters
- day/night mode changes character, palette and copy treatment
- no WebGL / no Three.js
- cards are allowed, but they must feel physical: torn paper, tape, clippings, tickets, stamps

## Asset philosophy
Do not generate a full website screenshot.
Generate isolated production assets only after the coded composition is reviewed.

Expected optional assets live under:
`public/demos/lwolf/assets/`

The page works before assets exist using CSS paper shapes and typographic placeholders.
